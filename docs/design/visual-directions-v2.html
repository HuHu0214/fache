公告

新粗野主义。把法律做成街边公告栏：粗黑边框、硬投影、荧光黄与电蓝、贴纸和盖章。适合强化“法律是公共信息”的直白与力量。

  • 结构 海报 + 公告栏
  • 关键词 粗野 / 直白 / 有冲击
  • 风险 长时间阅读会疲劳，适合入口与重点页

规范

五种语言共享一套组件语义、间距和圆角规则。风格可以极端，结构不能失控。

一、风格谱系

这次刻意选了五种不同的设计语言，而不是同一套视觉换五个色。它们的结构、材质、字体和动效都不同。

方向设计语言结构圆角适合
公告Neo-brutalism海报 / 公告栏0 + 硬投影入口、Boss、成就
软法Biomorphic / clay软盒堆叠14–36 squircle日常学习、陪伴感
LawOS 2000Y2K / chrome桌面窗口0–4实验性入口、活动页
判例矩阵Bento data12 列模块网格8–20主产品、复习、档案
法志Risograph杂志跨页 / 拼贴0品牌、专题、封面

二、令牌体系

组件只读语义令牌。风格切换只替换 primitive 与字体、圆角、间距的映射，不改组件 API。

:root {
  /* primitive */
  --ink-900: #1B1A17;
  --paper-50: #FAF7F0;
  --accent-500: #6B4BD6;
  --state-danger: #A33A32;

  /* semantic */
  --surface-page: var(--paper-50);
  --surface-card: #FFFFFF;
  --text-primary: var(--ink-900);
  --text-muted: #6C675E;
  --border-subtle: #D3CEC4;
  --action-primary: var(--accent-500);

  /* component */
  --button-primary-bg: var(--action-primary);
  --button-primary-fg: #FFFFFF;
  --card-radius: var(--radius-lg);
  --card-padding: var(--space-4);
}

三、圆角与间距

圆角按组件层级取固定档位，不写任意值。软法使用 squircle 连续圆角；公告与法志保持 0 圆角，作为语言的一部分。间距全部取 4 的倍数，嵌套容器等距内缩。

层级圆角间距
标签 / 条号0–2px4px 标签与值
按钮 / 输入4–12px8px 图标与文字
卡片8–20px16–24px 卡片内边距
浮层 / 软盒16–36px32–48px 页面区块
 
.soft-card {
  border-radius: 32px;
  corner-shape: squircle; /* 支持时使用连续圆角 */
}
/* 不支持时回退普通圆角；公告 / 法志则明确使用 0 圆角 */

四、组件语义

组件按场景选择，不按风格选择。以下规则在五种方向里都成立。

组件正确场景错误场景
主按钮一个视图唯一主行动导航、搜索、设置、多个并列主按钮
次按钮查看条文、返回、次级操作替代主行动、承载危险操作
展开器法条原文、解析、更多字段主行动、导航
危险按钮清除数据、放弃未保存内容收藏、取消、关闭
提示气泡护符规则、奖励概率、字段解释关键步骤、必读免责声明
Do

一个视图一个主按钮

主行动明确，次行动降级。

Don't

导航和主行动都做成主按钮

三个主按钮互相争夺注意力。

Do

法条用展开器

第 469 条▸ 展开原文

阅读节奏不被打断。

Don't

法条做成主按钮

条文是信息，不是行动。
