# 法径

一个按生活主题学习中国法律的本地 Web 应用。不做题、不考试，从真实场景进入，读完能落到法条原文，学过的内容用 FSRS 间隔复习留下来。

## 当前主题

- 合同：12 个场景、20 个知识点
- 婚姻：12 个场景、18 个知识点
- 劳动：12 个场景、18 个知识点
- 共 36 个场景、56 个知识点、3 个章节 Boss

内容采取保守写作：以法条原文的白话转述为主，操作建议统一标为「实务提示」。发布前需要对每篇的法条引用和「怎么办」部分做抽查复核。

## 启动

双击 `启动.bat`，或：

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173）。

## 怎么用

1. 首页是一条 36 场景 + 3 Boss 的主航线（合同 → 婚姻 → 劳动）：点发光的当前节点开始；完成并自评后，下一个节点才解锁。
2. 每章 12 个场景全部通关后解锁章节 Boss，通过 Boss 才能进入下一章。
3. 想自由浏览时，点主题名进入章节页，能看到全部场景和知识点，不受航线顺序限制。
4. 每天可以开一次宝箱，获得 20–30 阅历，可能掉落断签护符；连续打卡的每日阅历会递增。
5. 通关、开箱、Boss、升级都有粒子与音效；设置里可以关闭音效。
3. 点开场景先看问题，自己想一想，再展开答案。
4. 正文里的概念可以继续点开，法条可就地展开看原文。
5. 底部自评「没懂 / 大概懂了 / 很熟」，知识点进入复习队列；通关节点会亮起并给经验。
6. 复习页按到期时间出现，用自己的话回忆，再对答案。
7. 场景和知识点都可以写笔记、收藏；设置页「法修档案」有等级、经验、成就和存档管理。

## 加内容

内容在 `content/themes/<主题>/` 下：

- `theme.json`：主题信息
- `scenarios/*.mdx`：场景，frontmatter 里声明 `kpIds`、`primaryKpId`、`articleRefs`
- `concepts/*.mdx`：知识点，必须写 `reviewPrompt` 和 `reviewAnswer`

MDX 里可用：

```mdx
<ArticleRef law="civil-code" no="第四百六十九条" />
<ConceptLink id="contract-form">合同的形式</ConceptLink>
<Callout type="tip">实务提示</Callout>
<Steps><Step title="第一步">…</Step></Steps>
```

改完运行：

```bash
npm run content:validate
```

法条条号不存在、引用了不存在的知识点、场景漏了主知识点，都会报错。发布构建（`npm run build:release`）还要求所有内容 `reviewStatus: checked`。

## 更新法条

法条库在 `content/laws/*.json`，由脚本从 [just-laws](https://github.com/ImCa0/just-laws) 导入（该仓库数据来自国家法律法规数据库）：

```bash
npm run content:import
```

导入后重新运行内容校验，失效的法条引用会被指出来。

## 数据持久化

本项目没有后端服务器，是本地优先架构。学习进度、笔记、收藏、宝箱奖励、断签护符、Boss 通关状态都保存在浏览器的 IndexedDB 里，刷新、关闭浏览器后仍然保留。设置页导出的 JSON 包含上述全部字段，导入后会恢复。

如果需要跨设备同步，需要另外加后端（用户体系 + 数据库 + 同步协议），当前版本不包含。

## 数据备份

学习进度、笔记、收藏只存在浏览器的 IndexedDB 里。设置页可以：

- 导出完整数据（JSON）
- 导出笔记（Markdown）
- 导入备份（会覆盖当前数据）
- 清除全部数据

## 界面

采用「公告 × 法律图解」：首页、设置和程序页是公告栏风格；场景、知识点、法条、复习使用纸白阅读模式。颜色语义固定：黄 = 信息底，蓝 = 流程与主行动，品红 = 当前与注意，红 = 时限与危险。所有组件共享同一套颜色、圆角、间距和字号令牌。
